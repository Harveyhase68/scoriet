  PROFIL A — Projekt OHNE Migration (kein Diff zwischen Versionen):
      `migration.enabled` = false, alle nmaxmigration_* = 0
      → for-nmaxmigration_tables / fields / indexes / foreignkeys laufen 0×
      → migration.sql_complete = ''

  PROFIL B — Projekt MIT Migration (Diff zwischen v1 → v2):
      `migration.enabled` = true, `from_version` / `to_version` gesetzt
      → Echte Migrations-Operationen werden iteriert
      → nmaxmigration_total > 0
================================================================================

{:endfor:}

================================================================================

{:endfor:}
