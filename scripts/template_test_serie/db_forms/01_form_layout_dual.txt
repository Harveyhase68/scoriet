================================================================================
TEST FORM-01: FORM-LAYOUT (dual: ohne UND mit FormSet)
================================================================================
File-Type: db_table_file (mit form_window_type = 2 / create_edit)
Expected Output: 1× pro Tabelle.

WICHTIG: Dieselbe Vorlage wird in zwei Projekt-Konfigurationen ausgeführt:

  PROFIL A — Projekt OHNE FormSet:
      `nmaxformsets` = 0, `formset` = null
      → Alle for-nmaxlayoutsingles / for-nmaxlayoutbuttons-Schleifen
        laufen 0× (graceful skip)
      → `formset.name` u.ä. resolven zu '' (über optional chaining)

  PROFIL B — Projekt MIT FormSet "Standard":
      `nmaxformsets` = 1, `nmaxwindows` >= 1
      → Echte Layout-Elemente werden iteriert
      → `formset.default_button_color` etc. liefern Werte aus dem FormSet
================================================================================

Tabelle: {:tablename:}

================================================================================

nmaxwindows         = {:nmaxwindows:}

formset.description = {:formset.description:}

EXPECTED Profil A:
  nmaxformsets        = 0
  nmaxwindows         = 0
  formset.name        =        (leer — formset ist null)
  formset.description =        (leer)

EXPECTED Profil B:
  nmaxformsets        = 1
  nmaxwindows         = 3      (oder andere Anzahl je nach FormSet)
  formset.name        = "Standard"  (oder dein FormSet-Name)
  formset.description = "Default form set"
