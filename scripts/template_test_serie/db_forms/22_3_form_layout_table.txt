Exerziert das DATA-TABLE-Fenster des effektiven FormSets der Tabelle:

  PROFIL A — Projekt OHNE FormSet (oder Tabelle ohne Data-Table-Fenster):
      nmaxformsets = 0 / kein formtable → Loops laufen 0×, formtable.* = '' (optional chaining)

  PROFIL B — Projekt MIT FormSet (Tabelle hat ein Data-Table-Fenster):
      echte Spalten-Elemente + Werte aus formtable.*
