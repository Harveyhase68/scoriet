# Changelog

## 1.0.0 (2026-02-22)

- Initial release
- Inline translation previews for `t.key`, `__('key')`, `$t('key')` patterns
- Language cycling with Ctrl+Shift+L (cycles through all languages, then OFF)
- Hover card showing all translations for a key
- Configurable languages, locale file paths, and match patterns
- Supports JSON (flat and nested) and TypeScript/JavaScript locale files
- Auto-reload when locale files change
- Status bar indicator with current language
