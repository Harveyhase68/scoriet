# Template Store

The Template Store is Scoriet's community marketplace where you can browse, purchase, review, and download code generation templates created by Scoriet experts and the community. Instead of building templates from scratch, you can leverage existing, tested templates to accelerate your code generation.

## Understanding the Template Store

The Template Store provides:

- **Pre-built templates**: Ready-to-use code generation templates
- **Multiple technologies**: Laravel, React, Vue, Angular, .NET, Node.js, Python, etc.
- **Different use cases**: CRUD apps, APIs, Reports, Mobile apps, etc.
- **Community ratings**: See what other developers think
- **Free and paid options**: Some templates are free, others support creators
- **Regular updates**: Templates updated with security patches and improvements

## Accessing the Template Store

To browse templates:

1. **Click Template Store icon** in the dock
2. **The Template Store opens** showing featured templates
3. **Browse or search** for what you need
4. **View details** and reviews
5. **Purchase or download** templates

## Purchasing and Downloading

### Free Templates

1. **Click "Download"** button
2. **The template downloads** immediately
3. **No account/payment** required
4. **Starts importing** into Scoriet

### Paid Templates

1. **Click "Buy Now"** or "$29.99"** button
2. **Choose payment method**:
   - Credit/Debit card
   - PayPal
   - Digital wallet (Apple Pay, Google Pay)
3. **Complete purchase**
4. **License activated** in your account
5. **Download immediately**
6. **Lifetime access** to updates

### License Types

Different templates have different licenses:

**Personal Use**:
- Use for own projects
- Cannot resell generated code
- Single developer use
- Best for: Freelancers, small teams

**Small Business** (1-5 developers):
- Team of up to 5 developers
- Can use commercially
- Resell generated code
- Best for: Small agencies, startups

**Enterprise** (unlimited developers):
- Unlimited developers
- Full commercial rights
- Advanced features
- Priority support
- Best for: Large organizations

Check each template's license terms before purchasing.

## Managing Your Templates

### Installed Templates

In your main Scoriet app, see installed templates:

1. **Click "My Templates"**
2. **View all installed templates**
3. **See update available** badge if new version exists
4. **Access template** directly
5. **Manage** (update, uninstall, settings)

### Updating Templates

Get improvements and bug fixes:

1. **Click "Update Available"** badge on template
2. **Review what's changed** in changelog
3. **Click "Update"**
4. **New version downloads** and replaces old
5. **Your configurations** are preserved

### Uninstalling

Remove a template you no longer use:

1. **Right-click template**
2. **Select "Uninstall"**
3. **Confirm deletion**
4. **Template removed** (can reinstall later)

## Using Templates in Your Projects

### Applying a Template

1. **Create a new generator** or project
2. **Select "Use Template"**
3. **Choose from installed templates**
4. **Select your database schema**
5. **Configure template options**:
   - Language/framework version
   - Include features (auth, payments, etc.)
   - Styling theme
   - Output structure
6. **Click "Generate"**
7. **Code generated** based on template

### Customizing Generated Code

Templates are starting points, not final code:

1. **Review generated** code
2. **Customize as needed** for your project:
   - Change styling
   - Add business logic
   - Modify API endpoints
   - Update database queries
   - Add custom features
3. **Use version control** (Git) to track changes
4. **Regenerate** if template updates and merge changes

:::tip
Keep template-generated code in a separate branch so you can easily regenerate and merge updates.
:::

## Creating Your Own Template

Want to share your code patterns? Create a template:

1. **Build a generator** in Scoriet
2. **Create code generation templates**
3. **Test thoroughly** with different schemas
4. **Write documentation**
5. **Click "Publish to Store"**
6. **Set pricing** (free or paid)
7. **Submit for review**
8. **Once approved, appears** in Template Store

:::info
Template creators earn 70% of sales revenue. Popular templates can be a nice income stream!
:::

## Support and Issues

### Template Support

If you have questions about a template:

1. **Contact the creator** directly
2. **Check template documentation**
3. **Review reviews** for common issues
4. **Post in Scoriet community** forum

Most template creators provide:
- Email support
- Documentation
- Example projects
- Update notifications

### Reporting Issues

Found a bug in a template?

1. **Open template details**
2. **Click "Report Issue"**
3. **Describe the problem**
4. **Include steps to reproduce**
5. **Include your environment** (OS, browser, etc.)

The creator is notified and will investigate.
